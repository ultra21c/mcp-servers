# MCP Servers

다양한 MCP(Memory, Context, and Processing) 서버들을 모아놓은 프로젝트입니다.

## 서버 목록

- `daum-search`: Daum 검색 서버
- `aws-kb-retrieval-server`: AWS Knowledge Base 검색 서버
- `brave-search`: Brave 검색 서버
- `everart`: Everart 서버
- `fetch`: Fetch 서버
- `filesystem`: 파일시스템 서버
- `git`: Git 서버
- `github`: GitHub 서버
- `gitlab`: GitLab 서버
- `google-maps`: Google Maps 서버
- `gdrive`: Google Drive 서버
- `memory`: 메모리 서버
- `postgres`: PostgreSQL 서버
- `puppeteer`: Puppeteer 서버
- `redis`: Redis 서버
- `sequentialthinking`: 순차적 사고 서버
- `sentiment`: 감정 분석 서버
- `slack`: Slack 서버
- `sqlite`: SQLite 서버
- `time`: 시간 서버

## 설치 및 실행

각 서버 디렉토리 내의 README.md 파일을 참조하세요.
